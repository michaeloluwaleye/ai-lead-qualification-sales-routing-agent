# Deterministic qualification rules

Each dimension contributes 1–5 points, for a maximum total of 15.

| Company size | Points |
|---|---:|
| 1–10 | 1 |
| 11–50 | 2 |
| 51–200 | 3 |
| 201–500 | 4 |
| 501+ | 5 |

| Budget | Points |
|---|---:|
| Under £1,000 | 1 |
| £1,000–£5,000 | 2 |
| £5,001–£10,000 | 3 |
| £10,001–£25,000 | 4 |
| £25,001+ | 5 |

| Purchase timeline | Points |
|---|---:|
| Immediately | 5 |
| Within 1 month | 4 |
| 1–3 months | 3 |
| 3–6 months | 2 |
| 6+ months | 1 |

## Thresholds
- **Cold:** 0–5 → Brevo nurture
- **Warm:** 6–10 → Slack Warm
- **Hot:** 11–15 → Slack Hot

The valid inputs in the current model yield scores from 3 to 15; the Cold category includes the wider configured 0–5 threshold.

Required fields: Business Need, Company Size, Budget Range, Purchase Timeline and Email. Missing or unrecognised qualification values must be reviewed rather than silently scored.
