# Public publishing checklist

- [x] Explain the project as a self-directed simulated MVP.
- [x] Distinguish deterministic rules from autonomous AI.
- [x] Publish architecture, BA, scoring and UAT summaries.
- [ ] Inspect/redact screenshot emails, names, workspace identifiers and tokens before adding any images.
- [ ] Confirm all links and diagrams display correctly on GitHub.
- [ ] Link the repository from LinkedIn and CV when approved.
- [ ] Optional: add a demonstration video if created.
- [ ] For a real deployment, complete privacy/security review, monitoring, load testing and stakeholder acceptance.
